# SpectraLab Toolkit — documentación en línea

Centro de documentación científica de SpectraLab Toolkit Beta 1.9. Describe el
alcance, los datos requeridos, la metodología, las limitaciones, los
diagnósticos y los conceptos fundamentales de los módulos del programa portable.

La web es informativa: los cálculos se realizan en la aplicación portable para
Windows o macOS.
